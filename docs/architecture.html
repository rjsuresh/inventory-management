Factory Inventory Management System

System architecture, tech stack, and data flow overview

Overview

A full-stack demo application for tracking factory inventory, orders, demand forecasts, backlog, and spending. The frontend is a Vue 3 single-page app; the backend is a stateless FastAPI service backed by in-memory data loaded from JSON files — there is no database. All cross-cutting filtering (time period, warehouse, category, order status) is applied server-side via query parameters.

Design Notes

Filter System

Four global filters — Time Period, Warehouse, Category, Order Status — are passed as query params and applied identically across endpoints via shared apply_filters / filter_by_month helpers.

Reactivity Pattern

Raw API responses are stored in refs (e.g. allOrders, inventoryItems); everything derived — totals, chart data, filtered lists — lives in computed properties.

Statelessness

The backend has no persistence layer. Every write (e.g. creating a purchase order) is held in memory only and resets when the server restarts.

Design System

Slate/gray palette, semantic status colors (green/blue/yellow/red), custom SVG charts, CSS Grid layouts, no emojis in the UI.
